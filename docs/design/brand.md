# ResearchSpace 品牌标识

2026-10-08 · 研究轨道

抽象的 R 代表 Research，倾斜轨道表达探索路径，暖金节点表达发现。R 的开放空间与纸面工作台呼应，轨道与宇宙登录页呼应。采用原创 SVG 几何绘制，可无损放大，无外部字体和图片依赖。

- 浅色：蓝紫 #6858D6，轨道暖金 #B58C53。
- 深色：银紫 #ECE7FF，轨道浅金 #D8BA83。
- 单色：currentColor，适合印刷和小型水印。
- 最小推荐显示尺寸 24px；四周留出至少图标宽度的 1/6。
- 标识本身保持静止；操作反馈来自按钮或导航容器，不持续旋转。

文件位于 PaperQuery_Frontend/public/brand/。登录使用深色版、侧栏使用浅色版、浏览器使用独立圆角底板版 researchspace-mark.svg。
