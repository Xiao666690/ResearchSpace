# ResearchSpace 整站分镜

## 全站语法
远景用来建立探索感，近景用来承载可操作的研究证据。登录是暗色观测场；登录后是暖白桌面。相同的紫色强调、精密刻度、暖金时间意象和细线连接贯穿两种表面。导航固定、内容可滚动、临时详情浮在内容之上；页面差异通过构图体现。

## 页面角色与不可替换构图
| 页面 | 场景主旨 | 标志构图 | 主次与交互 |
|---|---|---|---|
| 登录/注册 | 从未知进入研究 | 全出血光环远景 + 右侧精密身份面板 | 巨大标题、轨道刻度、真实表单；功能说明是连续注释条 |
| 今日概览 | 把时间积累看得见 | 阅读沙瓶与今日行动并列 | 沙瓶连接真实分钟，其他指标是细密数据栏 |
| 项目列表 | 建立研究方向 | 项目档案列表 + 新建入口 | 搜索、项目状态、日期，空状态可创建 |
| 项目概览 | 观察完整研究链 | 目标横幅 + 文档/任务/成果层级 | 项目标签栏固定视觉规则，持续保持当前上下文 |
| 知识库/论文 | 可检索的档案 | 文件夹、密度可控列表、筛选工具 | 上传队列、加载/错误、长标题处理 |
| PDF/笔记 | 阅读与思考并存 | 文档舞台 + 可调整研究边栏 | 文档不透明，工具不遮挡正文，计时真实 |
| 智能问答 | 回答有来源 | 安静消息流 + 固定输入区 | 模型选择次要，引用/复制/停止清晰 |
| 研究任务 | 让执行过程可见 | 目标输入 + 任务轨道 + 成果侧栏 | 创建中防重复，状态真实，失败可理解 |
| 时间线 | 连接研究进展 | 连续纵向时间轴 | 事件类型、时间、来源、筛选 |
| 比较实验室 | 并列审视方法 | 同步阅读的对照表 | 横向滚动留在表格容器，单元格可展开 |
| 证据看板 | 整理支持与反证 | 分类证据列 + 详情浮层 | 原文、来源、可信度，删除确认 |
| 研究图谱 | 发现关联 | 留白画布 + 悬浮工具 + 详情侧栏 | 拖动直接跟手，布局不自动反复移动 |
| 成果工作室 | 从资料形成作品 | 模板选择/编辑/预览 | 保存有状态，导出不伪装成功 |
| 协作/团队 | 看清责任与权限 | 成员清单 + 审批操作 | 角色标签、授权与危险操作确认 |
| 全屏笔记/浮动问答/弹窗 | 保持任务连续性 | 内容聚焦，浮层有边界 | 焦点回归、Esc关闭、移动端适配 |

## 节奏与材质
登录远景为唯一强环境效果，正文先静态可见、短入场从暗处显现；身份面板从侧向建立层次，标题用裁切显现，底部注释直接可见。内页导航即时反馈；偶发浮层短过渡；阅读、键盘与流式消息不额外延时。
登录采用深蓝黑、暖金光环、冷银细线；工作区采用纸白、浅石灰、石墨文字、蓝紫强调。仅边界和浮层用阴影，不把每个列表都抬起。减少30%的装饰后仍然保留尺度、方向和层级。

## 用户授权与验收
用户已要求整站直接升级，分镜属于执行规范；不重复要求阶段审批。验证桌面1440/1280、平板768、手机390/320；验收真实登录/注册逻辑、数据错误、空数据、长文案、焦点、减少动态效果、构建。
