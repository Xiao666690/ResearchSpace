# 阅读体验实施说明

本文件对应 `TodayOverview.vue`、`ReadingVessel.vue`、`pdfInfo.vue`、`pdfViewer.vue`、`translateBox.vue`、`note.vue` 和 `NoteFullscreen.vue`。

## 今日时间沙瓶

数据直接来自 `GET /dashboard/overview` 的 `stats.readingMinutes`。瓶体只做显示，不向后端写入任何时长。装饰填充为 `min(1, max(0, minutes) / 60)`；60 分钟是标注的视觉刻度，既不是目标也不是上限。数字展示真实累计分钟，超过60分钟继续显示，0分钟瓶体为空。

SVG瓶体包含透明表面、细描边、瓶口、反光、静态颗粒和0/30/60刻度。暖金沙面通过 `translateY` 在瓶体裁切范围内移动；数据增加时以1200ms做一次解释性沉淀，用四次300ms颗粒流表达刚刚更新的真实记录。该时长属于信息可视化，控件点击仍120ms。定时器在新更新和卸载时清理；没有持续循环或伪造秒数，页面隐藏时概览停止定时请求。减少动态效果时沙面立即定位，颗粒流关闭。瓶体装饰 `aria-hidden`，容器的可访问名称含真实分钟与论文数。

概览60秒轮询；重复点击刷新不产生并发请求。已有数据刷新中仍可使用，失败时保留旧数据且标明错误，可重试。首次加载显示独立阅读轨道状态；首次失败显示错误与重试，避免永久“加载中”。各研究/论文列表空状态提供真实导航入口，论文标题可截断且键盘可操作。

## 阅读舞台

保留原有横向64/36可调整分栏与右侧翻译/问答纵向分栏。读者可拖动扩大阅读或讨论区。顶部清晰提供回论文库入口和记录规则；状态点表示PDF已加载，文字明确“在前台阅读时记录时长”，不声称失焦后继续计时。

`pdfInfo` 原15秒前台+焦点+loaded记录逻辑保持，并以相同规则覆盖全屏笔记中的论文阅读，未修改接口、数据库或计量方式。PDF显式加载、网络失败、解析失败、重新加载状态接入现有 `usePDF` 的 `onError`；鉴权fetch和对象URL资源回收保留。PDF滚动和翻页即时，缩放仍50%–250%、10%步进，Ctrl滚轮不变。正文纸面不透明，背景为浅石灰，工具栏暖白；没有对PDF内部canvas颜色或文本层做强制覆盖。

## 思考与笔记

翻译/笔记保留 `?tab=note` 深链接。两种内容 `v-show` 保留笔记编辑实例，切换不强制销毁Vditor。笔记顶部显示真实加载、未保存、保存中、已保存时间、失败状态；保存按钮宽度稳定，保存中禁用，Ctrl/Cmd+S即时。初次读取失败时暂停自动/手动保存并展示重试，避免用空笔记覆盖远端原稿。原剪贴板导入、本地Markdown导入、导出、全屏及自动保存均保留。

全屏返回直接导航，没有320ms等待，没有800ms弹性scale(0)入场。按下仅120ms微缩反馈，键盘导航和编辑输入不额外动画。移动端操作按钮换行；焦点用紫色清晰描边，减少动态效果去掉缩放。

## 已完成代码验证

`npx vue-tsc --noEmit --pretty false` 通过。未新增运行时依赖。没有全局样式或后端改动。

## 浏览器验收配方

1. 真实账户今日0分钟时沙瓶为空；读PDF并保持焦点至少15秒，返回首页刷新后分钟来自后端记录，增加一次填沙且停止。
2. 60分钟与超过60分钟数据瓶体满，主数字继续准确；360px/390px/768px/1440px检查数字、瓶体、长标题及入口不互相遮挡。
3. 系统减少动态效果模式下无颗粒流与位移，指标仍完整可读。
4. 断开后端：首页保留旧数据并有错误提示，首次进入不永久加载；PDF网络失败/损坏文件可重试。
5. 阅读页面滚动、Ctrl滚轮、分栏拖动、选区翻译、论文问答行为不变；PDF页码跳转没有装饰延时。
6. `?tab=note`直接进入笔记；键入、切翻译、再回笔记保留内容；Ctrl+S状态真实；加载失败禁止保存，重试成功恢复编辑。
7. 全屏返回即刻发生，保存/导入/导出/全屏入口焦点可见；键盘与触摸均不依赖hover。

真实论文渲染、模型响应和后端保存需要对应账号/资料/API进行端到端验证；类型检查不代表这些外部过程已成功。

## 路由复用与并发审计补充

Reader 的参数现在使用计算属性；论文、翻译、问答、笔记子组件按知识库/文档组合键重建，跨论文导航不会沿用旧资料或旧聊天状态。共用 `useReadingTracker` 在焦点/可见性边界累计真实前台时间，加载完成后开始，失焦时暂停；15秒发送整数秒并保留小数余量。切换文档时先向旧文档发送余额，重置ready再开始新文档；卸载发送最终余额并释放监听器/计时器。完整关闭浏览器时最后HTTP请求仍受浏览器中止限制，不承诺最后不足15秒一定上传。

PDF fetch 在重新加载和卸载时Abort，过期回包不会创建泄漏的对象URL。笔记保存队列保存的是内容快照而不是销毁后的编辑实例；请求期间的新增输入保持“未保存”并顺序发送下一版本。切换论文、进入/离开全屏时路由守卫等待真实保存完成；失败留在当前编辑页面供重试，避免新页面先读取旧数据。笔记读取失败/加载中编辑区域inert，避免键盘编辑不可保存内容。
