## 共享实现

`src/components/research/FeatureHeader.vue` 提供一致的页面层级，保留每页独立动作。`src/styles/feature-pages.css` 仅针对具名页面、面板与操作类；不操作 PDF canvas，不重绘图谱节点，不通过万能全局选择器替换功能布局。全局 tokens 和控制反馈由主实施负责。

## 已完成的局部检查

- 使用 `@vue/compiler-sfc` 对所属目录32个 Vue 文件执行 parse、compileScript、compileTemplate；使用 TypeScript transpile 对脚本语法检查：0错误。
- 最终完整 `vue-tsc --noEmit`、Vite 构建和真实浏览器验收由主实施统一执行，避免并发覆盖构建输出。
- 同一项目跨标签保留项目上下文；更换项目时子页重新获得新 projectId。
- 删除来源的证据、比较和工作室引用不提供可用原文按钮。
- 图谱同 ID 节点更新位置保持；新节点由原有布局确定；未新增自动播放、背景计时器或重型动画依赖。

## 验证边界

真实 PDF、带引用的流式回答、图谱构建、比较结果和长文稿仍需真实项目资料与模型调用才能验收内容正确性；空状态和界面样式不能证明模型输出正确。团队审批需要真实加入申请。报告最终验证状态以主实施实际结果为准。
